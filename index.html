REA MLS Listings API (v1)

A RESO Web API–style, read-only REST API that returns Multiple Listing Service (MLS) property listings as JSON. This is a demonstration API for Realtor.com data engineering.

Base URL

https://garniebolling-maia.github.io/realtor-dot-com

Authentication

None. This API is public and requires no API key, token or credentials.

Endpoints

MethodPathDescription
GET/v1/listings/page-1.jsonReturns the first page of property listings. Each page contains up to 500 listings.
GET/v1/listings/page-{pageNumber}.jsonReturns a specific page of listings. pageNumber is an integer starting at 1.

Pagination

Responses use next-link pagination. Each response contains an @odata.nextLink field holding the full absolute URL of the next page. Keep requesting @odata.nextLink until the field is absent or null; that is the last page. Records are in the value array.

Listing fields

FieldTypeDescription
ListingIdstringUnique listing identifier (natural key).
MlsIdstringSource MLS (e.g. MLS_MIDWEST, MLS_NORTHEAST, MLS_GULF, MLS_MOUNTAIN, MLS_PACIFIC).
MlsListingNumberstringListing number within the MLS.
PropertyIdstringReference to the property record.
StandardStatusstringActive, Pending, Sold, Expired, Withdrawn, Coming Soon.
PropertyTypestringSingle Family, Condo, Townhouse, Multi-Family, Land.
ListPricenumber, nullableAsking price in USD.
BedroomsTotalintegerBedrooms.
BathroomsTotalintegerBathrooms.
LivingAreaintegerLiving area in square feet.
ListingContractDatestring (ISO-8601 date-time)When the listing went live.
ModificationTimestampstring (ISO-8601 date-time)Last modification time.
Address.CitystringCity (nested object).
Address.StateOrProvincestringTwo-letter state (nested object).
ListAgent.AgentIdstringListing agent ID (nested object).
ListAgent.OfficeIdstringBrokerage office ID (nested object).

Example request

curl https://garniebolling-maia.github.io/realtor-dot-com/v1/listings/page-1.json

Notes

  • Filtering query parameters are not supported; every call returns the full page.
  • Data is synthetic and may contain data-quality issues by design.
